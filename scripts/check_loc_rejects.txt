# `prettier_intermediate*_*` kinds) carries no tsv-parse claim, because prettier's output is
# not always valid source: each document below is one prettier emits and the validity
# oracle for the syntax it breaks rejects — Svelte's parser for template syntax, tsc for

# (acorn-typescript, or Svelte's for the CSS one) accepts while tsc or the CSS spec rejects
# them: neither canonical parser is a validity oracle, so tsv rejecting them is the stance,
# not a gap.
